Sicherungen

    
Eigene Sicherungen der Welt, unabhängig von denen, die Valheim selbst
    rotiert. Dauerhafte werden nie automatisch gelöscht, die übrigen nur, solange mehr
    als zehn davon liegen. 

    
Hochladen nimmt ein tar.gz mit dem Weltordner (oder den alten
    .db/.fwl-Dateien) an, z. B. eine hier heruntergeladene Sicherung.
    Es wird dauerhaft abgelegt und erst über „Wiederherstellen“ eingespielt.

Konfiguration

      
Die Konfigurationsdateien der installierten Mods, so wie sie auf der Platte
      liegen. Die meisten Mods legen ihre Datei erst beim ersten Start an — vorher steht hier
      nichts. Beim Speichern bleibt die vorherige Fassung als .bak daneben liegen.


      
Der Server läuft. BepInEx schreibt die
      Konfiguration beim Beenden teilweise zurück — was jetzt gespeichert wird, kann dabei wieder
      verschwinden. Am besten gleich nach dem Speichern neu starten oder den Server vorher stoppen.

Paket für die Mitspieler

      
Ein Zip mit BepInEx und allen aktiven Mods, die als „für Clients“
      markiert sind. Die Spieler entpacken es in ihren Valheim-Ordner. Nach jeder
      Änderung neu bauen, sonst passen die Mod-Listen nicht zusammen und der Server
      lehnt die Verbindung ab.

Welt neu generieren

    
Löscht die aktuelle Welt, damit Valheim beim nächsten Start eine frische
    erzeugt. Vorher wird automatisch eine dauerhafte Sicherung angelegt —
    ohne die passiert nichts. Für Valheim 1.0 nötig, weil der Hohe Norden nur in
    unerforschtem Gelände entsteht.
